## Descrição
O repositório contém uma coletânea de exercícios realizados em sala de aula, usando a linguagem Python, organizados sequencialmente por variáveis, condicionais, estruturas de repetição e listas.  

## Tecnologia utilizada
Linguagem: Python  
Versão: 3.12.7  

## Como executar
Para executar os arquivos é necessário ter Python instalado no computador. Execute o exercício desejado utilizando o comando:
> python nome_do_arquivo.py

Exemplo:
> python exercicio1.py

## Índice dos exercícios
1. Exercício 1 - Crie duas variáveis com seu nome e sua idade. Exiba cada uma em uma linha.
2. Exercício 2 - Peça dois números ao usuário e exiba a soma dos dois.
3. Exercício 3 - Peça o raio de um círculo e calcule a área. Use 3.14159 como valor de pi.
4. Exercício 4 - Peça uma temperatura em graus Celsius e converta para Fahrenheit. A fórmula é F = C × 9 / 5 + 32.
5. Exercício 5 - Peça o preço de um produto e a quantidade comprada. Exiba o valor total, com duas casas decimais.
